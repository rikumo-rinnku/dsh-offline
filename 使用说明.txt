DeepSeek Harness 便携启动包（自带 Python 和 Node）

1. 将 ZIP 完整解压到本机 NTFS 磁盘上的可写文件夹。
2. 双击 start.bat，等待依赖链接准备完成，随后显示启动器。
3. 在启动器中启动服务，并在网页里配置自己的 API 凭据。

首次启动会创建依赖目录链接，不需要管理员权限，不需要下载依赖。
每次启动都会检查链接；整体移动文件夹后，再运行 start.bat 会修复旧路径。
不要在压缩软件内部直接运行 start.bat。不要只复制部分文件或合并不同版本。
本包面向已联网、但未配置 Python 和 Node 环境的 Windows 用户。
使用在线模型需要网络、有效凭据和相应服务。

.dsh-home 保存本人的配置和会话；.cache 为缓存；logs 为运行日志。
不要把已经运行过的整个目录再次直接压缩发给别人，否则可能包含凭据、
会话以及循环依赖链接。发布者应使用源码目录中的 _pack.ps1 重新生成发布包。

目录链接要求本地 Windows 文件系统支持 Junction；推荐 NTFS。
验证过的范围：GUI 模块加载、CLI 版本、网页启动与静态资源，以及整体移动后重建链接。
未执行真实模型请求或全部插件功能测试。
